# EKODIBIZ public shell release marker

This marker records the production release of the canonical EKODIBIZ public shell after PR #1052.

Release scope:
- EKODI home navigation from the EKODIBIZ brand
- browser-based Gmail inquiry composer
- business-area detail routing with partner login inside detail views only
- localized shared header, main content, detail views, and footer
- business areas including software, solar, commerce, consulting, trade, publishing, AI/digital operations, marketing/commerce, and investment

This file has no runtime behavior. It exists to make the production release trigger explicit and auditable.
