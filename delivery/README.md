# 배달허브 AI

배달허브 AI는 기존 주문·배달망 위에서 비용·시간·신뢰도를 비교하고 정산과 운영 판단을 돕는 배달 오케스트레이션 서비스입니다.

## 현재 운영 원칙
- Canonical URL: `https://ekodi.kr/delivery`
- 접근: 로그인 전 공개 안내 + 무료회원 이상 운영공간
- AI: 공급자 독립형 의사결정 지원
- 외부 배차: 공식 Adapter 연결과 사용자 확인 전까지 잠금
- 정산: 현재 단계에서는 미리보기와 운영 판단 지원

## 배포 흐름
`delivery/**` 또는 관련 Worker·설정 변경은 `Deploy Delivery Hub AI` 워크플로를 통해 검증 → 개발계정 격리 스테이징 → 보호된 운영 배포 → Canonical URL 검증 순서로 반영합니다.
