01 · STANDARD

EKODI Integration Standard

Identity

정체성은 Core에 남깁니다

외부 서비스는 별도 전역 계정 체계를 만들지 않고 EKODI의 Person·Workspace 권한을 최소 범위로 소비합니다.

Boundary

DB 대신 계약으로 연결합니다

서비스 간 private DB 직접 접근을 금지하고 API·Event·Webhook·Adapter·Gateway 같은 명시적 계약을 사용합니다.

Replaceable

Provider는 교체 가능해야 합니다

공통 Capability는 특정 공급자 API에 묶이지 않도록 연결층 뒤에 둡니다.

Human Authority

고영향 실행은 사람에게 남깁니다

L0 관찰부터 L4 실행까지 권한 상한을 명시하고 비가역·고영향 행동은 별도 승인 정책을 요구합니다.

02 · CONTRACT

공개 연결 계약

Service Manifest→Auth + Workspace→Capability→API / Event→Audit + Exit

내부 저장소·DB 구조·Secret·Provider topology는 공개 계약에 포함하지 않습니다. 공개 인터페이스와 검증 가능한 불변조건만 전달합니다.
