# EKODI 함께읽기 · 독서모임 플랫폼

Task: `reading-dialogue-workshop-20261103-01`
Reference: [Community Reading & Dialogue provider decision](../governance/proposals/reading-service-operator-20260910.md), issue #6416

## 소유권과 라우팅
- 공개 진입점: `https://ekodi.kr/community/reading` (Community 소관)
- 실제 모임 개설·가입·로그인: 기존 `/community/` Circle 기능을 재사용
- 도서 정보 원장: Books. 모임 운영 원장: Community. 사이트별 운영: 해당 서비스/사이트 관리자
- 별도 서브도메인, 신규 회원 테이블, 병렬 로그인, 중복 관리자 메뉴를 만들지 않는다.

## 첫 단계: 주제 탐색 및 진행자 도구
- 공개 주제 템플릿 6개: 《페스트》×코로나19, 희년, AI 윤리, 지역 공동체, 세대 간 대화, 고통과 성경
- 참여 대상에 따라 깊이 읽기·하브루타·사회 연결·낭독·온라인·실천형 모임 혼합
- 주제별 명시적 소요시간과 질문지, 진행 순서, 원문·공식 데이터 안내
- 질문 넘기기·진행안 복사·파일로 저장하는 개인 성찰·실천 기록
- 어떤 템플릿도 등록된 실제 모임·회원수·일정으로 가장하지 않음
- 개인 기록은 기본 서버 자동 저장이 없으며 동의 없는 자동 공유도 없음
- 실제 모임 개설은 중앙 커뮤니티의 로그인·역할·승인 흐름으로 위임
- PC·모바일 공개 열람과 한국어 어절 단위 줄바꿈 유지

## 《페스트》 표본 모임
- 10분 작품 이해 → 15분 역사·공식통계 → 25분 인물 대화 → 20분 철학·신학 → 10분 실천
- 국가별 누적 코로나19 수치의 시점과 보고 방식이 다르므로 통계 데이터는 고정 수치로 복제하지 않고 WHO 출처를 확인하도록 안내
- 저작권 있는 소설 전문·무단 번역 및 인용을 대량으로 보관하지 않는다.

## 후속 기능과 출시 조건 (이번 PR 범위 밖)
1. **서버 기반 모임 관리:** `books`, `clubs`, `memberships`, `meetings`, `reading_entries`, `attendance`의 정식 원장·이관 절차 및 서비스 소유권 확인.
2. **회원·권한:** 기존 EKODI 인증과 역할 연동, 모임장 승인, 참석 관리, 동의·삭제·반출, RLS 및 감사 기록.
3. **함께 읽는 공간:** 모임별 질문·답변·독서 기록, 자료실, 회차별 대화, 접근 권한 분리.
4. **모임장 아카데미:** 가이드, 진행자 역할, 경청·토론·아동 보호 원칙과 접근성.
5. **AI 활용:** 출처가 명확한 자료에 기반한 질문·요약·비교, 사람이 검토해 발행하며 원문 저작권 보호.
6. **알림·오디오·실시간 토론:** 참여 동의, 녹음·영상·음성 권한, 웹푸시, 비용·남용·개인정보 가드레일 확보 후 확장.
7. **운영 공개:** 보호 PR, CI, 승인된 Orchestrator release, 스테이징 PC·모바일·권한 시나리오, 실제 운영 URL 증거 확보.

## 검증 기준
- `node --test test/community-*.test.mjs`
- `node --check community-worker.js` 및 읽기 전용 JS 검사
- `npm run validate:deployments`, `npm run validate:orchestration`
- 배포가 끝나도 운영 `/community/reading` 공개 화면과 `/community/` 개설 흐름이 실제로 정상인지를 확인하기 전까지 완료라고 보고하지 않는다.
