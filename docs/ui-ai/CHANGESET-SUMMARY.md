# Change set summary

This branch establishes the official EKODI AI naming model, the USER UI / ADMIN UI governance split, and the My EKODI personal-assistant product boundary.

Completed implementation:
- My EKODI first screen is assistant-first.
- EKODI User AI is provider-independent and limited to suggest-and-handoff.
- The duplicate visible Workspace selector is eliminated through USER UI enforcement.
- Mobile top navigation is fixed with safe-area handling.
- User AI boundary/no-provider tests and My EKODI validation are included.
- EKODI Admin AI stays distinct as the ADMIN UI operations AI employee.
- Both roles connect through EKODI Core.
