# Fixed AI Boundary

EKODI User AI
개인 AI 비서
- 개인 컨텍스트를 이해하고 다음 행동을 제안한다.
- 전문 AI를 직접 지휘하지 않는다.
- 필요한 서비스로 handoff한다.

EKODI Admin AI
운영 AI 직원
- 운영 상태와 업무를 해석하고 관리자에게 제안한다.
- 관리자 권한과 Workspace 경계를 지킨다.

EKODI Core
에코디 생태계 공통 기반·연결 코어
- 두 AI 역할을 병렬로 연결한다.
- Identity/Auth, Workspace, Role/Permission과 서비스 연결을 제공한다.
