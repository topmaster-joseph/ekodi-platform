# EKODI Admin AI System

## EKODI Admin AI
운영 AI 직원

ADMIN UI의 중심 AI 역할. 운영 상태, 승인 대기, 실패 작업, 서비스 상태와 지표를 해석해 운영자의 다음 행동을 제안하고 보조한다.

## Boundary
- EKODI User AI와 역할·권한을 분리한다.
- 사용자 개인비서 역할을 대신하지 않는다.
- Workspace와 Role/Permission 경계를 준수한다.
- EKODI Core를 통해 필요한 운영 컨텍스트를 연결한다.
- 특정 AI 공급자가 없어도 기본 운영 화면과 상태 확인은 유지한다.
