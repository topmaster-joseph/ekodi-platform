# Development Naming

Use these canonical names in code, workflows, dashboards, and runbooks:

- Branch: `development`
- GitHub environment: `development`
- Cloudflare account: `EKODI Development`
- Worker: `ekodi-platform-development`
- Worker subdomain: `ekodi-development.workers.dev`
- Deployment token secret: `CLOUDFLARE_DEVELOPMENT_API_TOKEN`

Avoid ambiguous labels such as `dev2`, `test-prod`, or `temporary` for this environment.
