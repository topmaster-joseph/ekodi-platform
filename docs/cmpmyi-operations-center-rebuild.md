# CMPMYI 통합 운영센터 재구성 명세

## 원칙
- 통합 허브: /cmpmyi/admin, 매장별 정식 URL: /jadam/admin, /pizzamaru/admin, /yogurt/admin.
- 통합 UI는 상태와 진입점만 모으며 데이터 읽기/쓰기 및 권한 검증은 매장별 서버 경계에서 수행한다.
- 사용자/관리자는 동일 매장 UI를 사용하고 권한별 관리 동작만 노출한다.
- 실제 연동 없는 KPI를 0이나 정상으로 표시하지 않는다. 미연동/지연/오류/정상 구분 및 갱신시각을 표시한다.

## 정보 구조
1. 운영홈: 전체 매장 상태, 매출/주문 집계(연동 시), 오류, 빠른 조치.
2. 매장 운영: 주문, 메뉴·가격, 재고, 고객·리뷰, 매장업무.
3. POS·연결: POS Agent 설치·진단·하트비트, 배달 플랫폼 연결, 계정 갱신.
4. 영업자동화: Marketing AI, 채널 게시, 승인대기, 실행 로그.
5. 매출·정산: 매출, 비용, 수수료, 정산 및 누락 확인.
6. 분석·보고: 매장 비교, 기간 필터, 일일 보고.
7. 시스템: 매장별 권한, 감사로그, 장애 복구.

## 구현 게이트
- 현재 store-portfolio-admin-page.js의 공통 뷰 및 매장별 canonical 링크를 재사용하고 데이터 저장소를 통합하지 않는다.
- 3개 브랜드에서 경로 직접접근/새로고침, 세션 유지, 권한 격리, 모바일 레이아웃 테스트.
- POS Agent 실제 PC 통신 확인 전 '연결됨' 표시 금지.
- 기존 레거시 삭제는 데이터 이관, 기능 동등성, 롤백 실증 후 별도 승인 게이트.
- PR CI 및 스테이징 확인 후 운영 배포; 운영 URL 응답과 핵심 기능 실증 전 완료 표시 금지.
