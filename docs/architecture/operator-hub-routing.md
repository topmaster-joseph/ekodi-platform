# Operator Hub Routing Contract

1. Ordinary users do not route through `/my/` merely because they possess an EKODI person ID.
2. Authentication returns users to the site-local return target when that target is valid and authorized.
3. `/my/` is reserved for authenticated operators and presents only admin/service destinations derived from existing authorization.
4. A site-admin destination remains canonical under the owning site's administration surface; `/my/` is a launcher and summary layer only.
5. Shared services can be embedded or linked in the owning site's context without exposing the My EKODI product name.
