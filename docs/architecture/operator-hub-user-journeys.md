# Operator Hub User Journeys

## Ordinary user

1. Opens a branded site.
2. Authenticates through shared EKODI identity only when required.
3. Returns to the same branded site context.
4. Uses shared services there without being sent through My EKODI.

## Operator

1. Opens `https://ekodi.kr/my/` or an authorized operator entry.
2. Authenticates through EKODI identity.
3. Sees only assigned sites/services, pending work, health and alerts.
4. Opens the authoritative admin surface for the selected site/service.
5. Returns to My EKODI for cross-site summary and follow-up.
