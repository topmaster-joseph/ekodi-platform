# Operator Hub Admin Link Contract

My EKODI may list an administration destination only when the central identity/authorization layer confirms the signed-in person already holds the corresponding operator role or delegated site-management permission. The hub stores no parallel authority table and never promotes access based on UI visibility, URL knowledge, or inferred tenancy.

Each destination should identify the owning site/service, role scope, health summary, pending work count, and canonical admin URL. The canonical admin surface remains owned by that site/service.
