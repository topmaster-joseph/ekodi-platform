# Operator Hub Acceptance Criteria

- `/my/` is described and presented as an operator workspace, not a general member home.
- Ordinary end-user sign-in flows return to the originating site context rather than routing through `/my/` by default.
- Operator cards/links are filtered by existing authorization and never create access.
- Each site keeps its own authoritative admin UI and brand language.
- EKODI Identity remains shared infrastructure independent of My EKODI.
- `my.ekodi.kr` remains compatibility-only.
