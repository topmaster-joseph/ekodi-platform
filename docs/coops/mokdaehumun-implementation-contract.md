# 목대후문 자율상권조합 — 구현 계약 (초안)

경로 제안: /mokdaehumun (기존 라우트 충돌 검증 후 확정).

## 공개 화면
소개, 공지, 행사, 상권 소식. 회원 개인정보 및 출자금은 절대 공개하지 않는다.

## 내부 화면
EKODI 통합 Google 인증을 신원확인에만 사용한다. 로그인 시작 경로/쿼리로 복귀한다. 조합별 서버 측 인가를 모든 조회/변경 API에서 검증한다. 관리자에게는 사용자 화면 안에서 회원 등록·수정·삭제, 출자 약정·납입·환급 관리, 회의록·감사 로그를 제공한다.

## 데이터 모델
coop_id, member_id(UUID), name, contact_encrypted, address_encrypted, membership_status, joined_at, share_pledged_krw, share_paid_krw, updated_at. 납입 기록은 별도 append-only ledger (transaction_id, member_id, amount, kind, occurred_at, actor_id, evidence_ref). 출자금 합계는 원장과 대사한다. 주민등록번호는 수집/저장하지 않는다. 원본 사진은 공개 저장소/CI 로그/정적 파일에 넣지 않는다.

## 마이그레이션
첨부 종이 명부의 10명 및 출자금 5,430,000원은 검수 전 임시 집계이며 납입 사실을 뜻하지 않는다. OCR/수기 검수와 동의·권한 확인 후 관리자 전용 안전한 입력 경로로만 이관한다. 공개 테스트 데이터는 가명으로 생성한다.

## 완료 조건
1. 공개/조합원/관리자 권한 분리 및 타 조합 접근 차단.
2. 로그인 반복 없이 최초 URL 복귀.
3. 회원 CRUD, 출자 원장, 감사 로그, 백업/복원 테스트.
4. 민감정보 비노출(HTML, API, 로그, Git, 검색엔진) 테스트.
5. 필수 CI, 보호된 병합, 스테이징, 자동 롤백, PC/모바일 운영 검증 후 완료 선언.

이 문서는 설계 계약이며 배포나 실제 DB 이관 완료를 의미하지 않는다.
