# EKODI 공유 링크·신규 가입 확인 기반 활동포인트

**공유 시도와 보상 확정은 서로 다릅니다.** 앱의 공유 버튼 클릭, 공유 시트 열기, 링크 복사, SNS에 게시했다는 자기 신고만으로는 절대 포인트를 지급하지 않습니다.

## 데이터 검증

- `ekodi_points_issue_share_invite(site)`: 서버가 UUID 초대코드를 발행하며 포인트 원장에는 기록하지 않습니다. 실명·이메일은 링크에 포함하지 않습니다.
- `ekodi_points_confirm_shared_signup(invite_code)`: 실제로 로그인·인증된 사용자의 세션에서만 실행할 수 있습니다. 서버는 `login_identities`와 `people`의 통합 EKODI 신원을 조회합니다.
- 가입자는 기존 가입자가 아니어야 하며, 초대코드 발행 이후 새로 생성된 활성 `people`여야 합니다. 초대 유효기간은 14일, 새 회원 확인 기간은 7일입니다.
- 같은 EKODI Person의 자기초대와 사이트별 중복 보상을 막습니다. 다른 외부 소셜계정이 동일 EKODI ID로 연결되면 그 Person을 공유합니다.
- 1회 적립은 1~5P, 일일 최대 25P/5건, 초대코드 발행은 일일 3건까지로 제한합니다. 기존 전체 사이트 상한도 함께 적용됩니다.
- RLS/권한: 일반 브라우저의 초대·결과 테이블 직접 조회와 쓰기를 금지합니다. 명시적 인증 RPC만 제한적으로 실행합니다.
- 가입자가 받은 결과에는 초대한 사람의 원장 잔액이나 개인정보를 반환하지 않습니다.

## 출시 전 확인

기본 사이트·규칙은 비활성화됩니다. 실제 페이지와 OAuth 가입 인계에 연결하기 전, 가입 완료 시점·브라우저 복귀 주소·다중 계정 분리·기존 회원 예외·가입 유도 남용·오토메이션 계정·일일 상한·최종 데이터 보존 정책을 실증해야 합니다.

**주의:** 인증된 새 계정이라는 사실은 링크 공유가 특정 SNS에 실제로 게시되었다는 증명이 아닙니다. 따라서 명칭은 ‘확인된 신규회원 초대’로 한정하고 고액 전환·현금성 혜택에 연결하지 않습니다.
