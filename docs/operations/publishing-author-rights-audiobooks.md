# EKODI 출판 통합 저자 정책 — 저작권·집필 권한·오디오북

- 정책 제안 승인: 2026-10-29 사용자 지시
- 소유 서비스: 에코디출판 `/publishing`; 집필 스튜디오: `/publishing/human`
- 통합 지휘: EKODI Orchestrator. 에코디서점 `/books`, 에코디몰 `/ekodimall`은 승인된 판본만 계약 API로 소비한다.
- 상태: 이 문서는 규정과 순수 정책 게이트 정의이며 운영 로그인·결제·오디오 생성·유통 배포 완료를 뜻하지 않는다. 실서비스 API는 추가 보호 PR, CI, 보안 및 운영 실증 후에만 활성화한다.

## 1. 등급별 권한 (서버에서만 판정)

| 기능 | 무료 | 유료 writer1/writer3 | 최고관리자 + 출판편집 scope |
|---|---|---|---|
| 전 분야 영감 발굴·집필 전문가 지도 | O | O | O |
| 기초 집필·개인 원고 저장·내보내기 | O | O | O |
| 다단계 대화형 휴먼 집필 | X | O | O |
| 별도 분야별 기획집필/자동 예약 | X | X | O |
| 판매등록 심사 요청 | X | O(별도 계약) | O |
| 승인된 판매도서의 구매자용 무료 고급 오디오북 | 해당 없음 | 필수 | 필수 |

무료 집필 결과는 비공개 개인 보관/내보내기까지 가능하며 ISBN, 판매 카탈로그, 공개 유통 이벤트, 유상 결제/구매자 접근권한을 생성하지 않는다. 무료 원고를 나중에 유료로 진행해도 과거 프로젝트는 구독 사용량으로 소급 계산하지 않는다. 유료 구독은 휴먼 집필 도구의 이용권이며, 완성·발행·판매를 보장하지 않는다.

기존 제안 금액은 writer1 월 100,000원(신규 1프로젝트), writer3 월 150,000원(신규 3프로젝트). 부가세, 갱신/취소/환불, 이용량, API 사용 예산 등 약관 승인·결제 연동 전까지 실제 청구 금지. 최고관리자 기획집필은 별도의 서버 확인된 최고관리자와 출판 편집 범위가 **둘 다** 필요하다. 이메일 문자 일치, 브라우저 쿼리, 클라이언트 역할만으로 권한을 주지 않는다.

## 2. 모든 분야에 공통인 전문가 집필 지도

분야(문학·신학·인문·학술·경영·교육·예술·과학·건강·실용 등)를 제한하지 않는다. 모든 저자가 동일한 기본 영감 코칭을 받을 수 있고, 무료회원에게도 배제하지 않는다. 작가의 실제 경험과 관찰, 목적 독자, 중심 질문, 구조, 장별 주장·장면, 반론과 독자 관점, 교정·편집, 마무리 성찰을 단계적으로 이끈다. 개인 인터뷰 기록은 저자의 명시적 답변과 동의로만 축적한다.

분야별 지침은 비평적인 사고와 독창적 문체를 지원하고 편향·고정관념·근거 없는 인용·허구 경험의 사실화, 전문자격의 허위 표방을 금지한다. 고위험 의학·법률·재무 사실은 적절한 인간 전문가 확인을 추가한다. 유료회원은 심층 대화와 반복 편집을 제공하되 창작과 최종 검수의 주체는 저자이다.

## 3. 저작권과 출판 허락

원칙: **모든 회원의 인간 저자가 창작한 원고 저작권은 저자에게 귀속**된다. 회사·서비스가 일괄 양도받거나 회원 등급에 따라 저작권을 빼앗지 않는다. 다만 AI만으로 생성된 부분의 저작물성은 법적 요건에 따라 다르므로 자동 독점권을 보장하지 않는다. 원작 인용, 사진, 초상, 공동저자 및 제3자 자료는 개별 권리 확인이 필요하다.

판매·출판 시 별도 라이선스에 허락 범위(전자책·오디오북·인쇄판·채널·기간·지역·철회·수정·마케팅 이용)를 특정한다. 저작권 귀속과 출판사가 이용할 권리는 구분한다. 변경된 판본의 다이제스트는 이전 승인을 무효화한다. 무료 회원의 개인소장 기능은 출판사에 판매·배포 라이선스를 부여하지 않는다.

유료회원의 판매 인세율과 유통·판매수수료는 **구독료와 별개로 체결한 계약**에서 합의하며, 미합의/무서명은 fail-closed. 예: 인세 산정기준, 플랫폼 판매수수료, 결제수수료, 세금, 환불 차감, 정산 주기, 외부 채널, 보고·해지 규칙. 임의의 인세율/수수료율을 부여하지 않는다. 저자의 판본별 동의와 출판사 별도 승인이 모두 필요하다.

## 4. 판매 전 무료 고급 오디오북 의무 게이트

유료 이상 저자가 완성하여 실제 판매등록한 **모든 도서**에는 구매자에게 추가금 0원인 오디오북 번들을 제공한다. 구매자는 승인된 EPUB/인쇄책 등 도서 상품 구매 권한을 증명하면 연결된 판본의 고급 오디오북에 접근한다.

- 본문과 화자/대화 구분을 장면별로 구조화. 나레이션과 대화의 발음·억양·간격·감정선 자연스러움 검토
- 고급 음성 엔진 사용 시 승인된 공급자와 라이선스 및 사용료 상한 준수; 유료 API 자동 결제 금지
- 낭독 누락·중복·오독, 장별 음량 정규화, 청취 테스트(실제 사람), 음악·효과음 저작권 확인
- 승인된 최종 원고 판본 다이제스트에 오디오 마스터를 결합. 원고 수정 시 해당 음성 재검수
- 인증된 구매자 서재에서 접근. 서점·몰 공통 구매권한을 안전하게 확인하고, 취소·환불 시 정책에 맞게 접근 철회
- 오디오북 별도 상품에 추가 요금을 자동 청구하지 않으며, 출판사의 오디오 제작비와 저자 계약을 분명히 구분
- 제작·품질 승인 또는 구매자 권한/환불 처리가 미검증 상태라면 **판매등록을 보류**하고 준비 중으로 표시

이 정책은 MP3/M4B 렌더링이나 실서비스 다운로드가 이미 동작한다는 주장이 아니다. 고품질 실제 음원 생성, 라이브 결제 연동 및 구매 후 제공 실증은 별도 단계다.

## 5. 안전한 상태 흐름

1. 저자 신원·회원 등급을 백엔드에서 확인하고 비공개 집필 프로젝트 생성
2. 모든 등급의 영감 코칭 진행. 유료/출판편집자는 별도 심층 집필 진행
3. 저자가 저작권·타인 자료 권리 및 최종 원고 다이제스트 승인
4. 무료: 개인보관/다운로드로 종료, 어떤 판매등록도 불가
5. 유료: 라이선스·판본별 인세/수수료 계약을 별도 서명 확인 후 심사 요청
6. 최고관리자: 검증된 출판편집 scope로 기획집필을 별도 작업 큐에서 실행
7. 출판사의 사실·권리·접근성·EPUB·공급채널·도서정가·결제 심사, 오디오 품질/무료 구매권한/환불 철회 검증
8. 출판사 서명과 일치하는 고정 판본만 멱등 이벤트를 통해 서점·몰에 전달, 서재와 원장 검증 후 판매

## 6. 필수 회귀 실증

- 무료 프로젝트 판매등록 차단, 비공개 원고 보존, 구독 업그레이드 시 동의 기반 별도 계약
- 미인증·구독 만료·타 저자 원고 접근 및 위조 최고관리자/편집 scope 차단
- 유료 원고에 서명 계약·인세·판매수수료·판본 digest 미일치 시 보류
- 모든 분야 코칭이 회원 등급에 무관하게 사용 가능한지 검증
- 고급 오디오북 없음/품질 미검증/유료 추가금/잘못된 판본/환불 후 접근 유지 시 판매 차단
- 서점·몰 가격·정본·구매권한 동일성 및 기존 도서·기존 인세·운영 데이터 무변경 확인

마지막 결과는 PR/SHA/CI/스테이징/운영 검증을 따로 기록한다. 운영 배포, 실제 저자 계약, 결제 승인에 관한 근거 없이는 '구축 완료'라고 보고하지 않는다.
