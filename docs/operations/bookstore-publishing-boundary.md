# 에코디서점 ↔ 에코디출판 운영 경계

## 공식 명칭

- 공개 서점 서비스의 공식 명칭은 **에코디서점**이다.
- `books`는 호환성과 기존 API/경로 유지를 위한 내부 service id일 뿐, 사용자 노출 브랜드로 사용하지 않는다.
- 독립 출판 전문서비스의 공식 명칭은 **에코디출판**이다.

## 역할 분리

### 에코디서점 (`books.ekodi.kr`)

도서 탐색, 카탈로그, 판매 전시, 개인·기관 서점 storefront와 commerce 연결을 담당한다. 출판 상담·제작·출판대행·외부 유통 실행을 자기 하위 기능으로 소유하지 않는다.

### 에코디출판 (`publishing.ekodi.kr`)

출판상담, 제작, 출판대행, 유통 준비, Publishing Studio, UPaper 지원을 담당하는 독립 전문플랫폼이다. 에코디서점과 별도 Worker·배포 경로·운영 검증을 갖는다.

## 연결 원칙

에코디서점은 에코디출판을 독립 서비스 소비자 관점에서 이용한다. 두 서비스 사이의 연결은 공개 또는 명시적으로 선언된 API·handoff 계약으로만 수행한다. 어느 한 서비스도 다른 서비스의 사적 저장소나 테넌트 데이터를 직접 읽거나 쓰지 않는다.

기존 `books.ekodi.kr/publishing/*` 경로는 호환성만을 위해 `publishing.ekodi.kr`로 영구 리디렉션할 수 있다. 이 리디렉션은 에코디출판이 에코디서점의 하위 모듈이라는 의미가 아니다.

## 배포 및 승격

에코디출판은 PR마다 격리된 staging Worker에서 검증하고, production은 guarded release 후 실제 `publishing.ekodi.kr` 호스트를 다시 검증한다. 운영 상태 승격은 staging, CI, production host 검증이 모두 성공한 뒤에만 수행한다.
