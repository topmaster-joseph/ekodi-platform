## 정식 CI 재검증의 목적
EKODI가 기존 보호된 `main` 내용을 복구 PR에 동기화했지만, 봇 생성 커밋은 GitHub가 PR 체크를 `action_required`로 처리할 수 있습니다. 이 **문서 전용 원 소유자 변경**은 최신 동기화 SHA에 대해 실제 필수 PR 체크를 실행하기 위한 것입니다. CI 결과는 실제 Actions 검증으로만 인정하며 상태를 조작·면제하지 않습니다.

검증 순서:
1. 원래의 `7ab5098f128ea13dce2c02f48c8ed379817a7717`가 복구 브랜치 조상인지 확인
2. 소스 코드 문법 및 `test/search-visibility-admin.test.mjs` 포함 CI 확인
3. EKODI 오케스트레이션, 병렬 충돌 방지, 하위도메인 금지, 관리자 런타임 계약, 보안, DB 검증
4. 보호된 PR 병합 이후 실제 Site Core 가드 배포 및 운영 URL 점검
5. PC/모바일 공개 페이지에서 실제 DOM 한 줄형 목록·분류 필터·상세 관리 버튼·권한·근거 표시 검증

PR/커밋/배포 성공을 실서비스 검증 성공으로 추정하지 않습니다. 증거 미확보 상태에서는 완료로 표시하지 않습니다.
