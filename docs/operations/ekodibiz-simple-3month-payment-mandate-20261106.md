# EKODIBIZ — 3개월 생성형 AI 구독료 결제위탁 (최소 운영안)

- Task: `ekodibiz-simple-mandate-20261106`
- 기존 경로: `https://ekodi.kr/ekodibiz/ai-agency` / `https://ekodi.kr/ekodibiz/ai-agency-admin`
- 운영법인·사업자: 에코디비즈 개인사업자 (새 법인·새 PG·새 사이트 불필요)
- 작업 성격: 기존 신청/견적/계약동의/수납 시스템에 **수동 결제증빙·갱신중단 증빙·정산 CSV**만 추가하는 코드 후보. 운영 배포 완료를 뜻하지 않음.

## 한 건의 위탁 흐름
1. 대학이 신청한다. 대학 이름, 담당자 연락처, 해당 AI 서비스와 **3개월** 계약기간을 확인한다.
2. 에코디비즈가 견적을 낸다. **위탁료**와 **해외 공급사 구독료 예산**을 분리한다. 공급사 구매/수납 승인 없이 구독료를 수납하지 않는다.
3. 대학이 계약에 동의하고 기존 합법적인 수납 방법으로 납부한다. 공급사 이용 개시 여부를 담당자가 확인하기 전에는 이용기간이 시작된 것으로 처리하지 않는다.
4. 담당자는 월별 결제영수증의 식별번호, 실제 지급액, 지급일을 **최대 3회 기록**한다. 기록은 결제를 실행하지 않으며, 중복 회차·영수증 및 총 계약예산 초과를 차단한다.
5. 실제 공급사에서 자동갱신 중단을 확인한 뒤 **해지 확인번호만 기록**한다. 개인 계정과 대화기록은 삭제하지 않는다. 대학에는 별도 정산 요약 CSV를 제공한다.

## 계약 후 대학·에코디비즈·개인 이용자 화면

추가 도메인 또는 대학 전용 별도 계정을 생성하지 않는다.

- **대학교 담당자**: 기존 `/ekodibiz/ai-agency`에 발급받은 신청번호 + 비밀 조회코드를 입력하면 본인 계약의 3개월 요약 화면이 노출된다. 신청/견적/계약 상태, 3회 수동 지급증빙 기록, 위탁료/공급사 예산/미배정 금액, 갱신중단 증빙 등록 여부, CSV 정산요약 조회. **비밀 조회코드는 계약 담당자가 보관하고 공유 범위를 관리**한다. 아직 대학 전체 조직의 SSO 역할 인증이 아니라 해당 계약 단위의 소지자 인증이다.
- **에코디비즈**: 기존 `/ekodibiz/ai-agency-admin`에서만 견적과 수동 지급·종료 증빙을 입력·관리한다. 관리자 서버키 없이는 해당 API 403.
- **개인 이용자**: 공급사의 기존 개인 계정을 계속 사용한다. 에코디 별도 계정 생성, 개인 비밀번호 입력, 대화내역 열람 기능을 추가하지 않는다.
- **접근 경계**: 기존 `/api/agency/status`는 신청번호 + 비밀 조회코드 해시 검증 후 `campus` 집계 속성만 함께 반환한다. 대학 A의 조회코드로 대학 B 계약은 조회 불가. 개인 1개월 신청에는 `campus:null`.
- **자료 검증 한계**: 대학 조회의 월별 금액과 확인번호는 관리자 수동 기재. 사용자의 실제 유료 구독 활성화/취소, 공급사 청구원본, 은행잔액, 환불액은 독립 검증하지 않는다. 민감한 영수증 원본·이용자 명단을 노출하지 않는다.

## 기존 화면에서 추가한 운영자 기능
- `POST /api/agency/admin/record-cycle`: 관리자 인증 필요; `{id,cycle,amount,paidOn,receiptRef,confirmed:true}`. 결제 호출 없음.
- `POST /api/agency/admin/stop-renewal`: 관리자 인증 필요; `{id,cancellationRef,personalAccountKept:true,confirmed:true}`. 공급사 구독 해지 호출 없음.
- `POST /api/agency/admin/settlement`: 관리자 인증 필요; 수동 증빙 합계와 미배정 구독료 예산 조회. 출금 또는 환불 API가 아님.
- 모든 데이터는 기존 `REVENUE_STORE`의 `agency:` 계약 기록에 추가된다. 개인 AI 로그인, OTP, 결제카드, 대화내용 저장은 금지한다.

**정산상 주의:** 수동 증빙 합계와 미배정 예산은 실제 은행잔액, 최종 부가가치세, 확정 환급액 또는 공급사 잔액으로 표현하지 않는다. 은행/PG 거래와 영수증을 별도로 대조한다.

## 간단한 3개월 결제위탁 계약 필수 조항 (사업용 초안)
- **계약 당사자:** 위탁자(대학교 또는 산학협력단 등 서명 권한이 있는 발주기관) / 수탁자(에코디비즈)
- **업무 범위:** 승인된 해외 생성형 AI 공급사에 한정하여, 명시된 대상자와 수량의 구독료를 3개월 동안 위임받아 결제 및 결과 정산
- **금액:** 이용료 예상 총액 `____원` + 대행 수수료 `____원`; 부가세 포함 여부와 환율·해외 결제수수료 처리 명시
- **지급 조건:** 위탁대금 선입금/후정산 등 발주조건 및 미지급 시 업무 중단 기준을 서면으로 정함
- **이용자 개인정보:** 본인 소유 개인 AI 계정 유지, 비밀번호·OTP·대화기록 수집 금지, 이용자 동의 및 명단 최소 수집
- **안전 조건:** 공급사 제3자 결제 허용 서면증빙, 관련 국내 PG·외환 의무 확인 전 실제 대납 결제 없음
- **3개월 종료:** 공급사 실제 구독 해지/갱신중단 정책을 따라 확인번호를 확보. **관리기간 종료만으로 공급사 자동갱신이 중단됐다고 간주하지 않음**
- **정산 및 환불:** 지급 영수증·미사용 대금·수수료·환율차이·환불 처리방법을 구분. 정산서 확인 및 이의제기 기간은 실제 계약에서 합의
- **공급사 정책 변경·결제 실패:** 즉시 통지하고 미집행 부분을 협의. 공급사 제3자 결제를 허용하지 않으면 임의 카드 대납을 시행하지 않음

**법적 상태:** 계약 명칭만으로 전자금융거래법상 PG 등록이 면제되지 않는다. 금융위원회 공식 법령해석 접수번호 미확보, 한국은행 회신과 공급사 서면 승인 미확보. 기존 `AGENCY_*` 결제 활성화 설정은 명확한 승인/거버넌스 심사 없이 변경 금지.
