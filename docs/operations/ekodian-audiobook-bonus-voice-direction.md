# 에코디언 오디오북 보너스/낭독 연출 가드 v1

## 원칙
- 해당 전자책의 **유효한 구매권한 보유자**에게 동일 책 오디오북을 추가 비용 없이 제공한다.
- 에코디 직접구매는 서버의 books_entitlements(buyer_user_id, book_id, revoked_at)만으로 결정한다. 구매 시도·회원등급·표면적 로그인 여부는 증명 아님. 환불/권한회수 시 음원 접근도 즉시 차단.
- 유페이퍼 등 외부 판매처 구매자는 판매처 확인 가능한 구매 인증 프로세스가 구성될 때까지 자동 권한 지급 금지. 별도 결제 요구 금지.
- 구매자별 접근은 인증된 /books/api/commerce/audiobook/{bookId}/track/{number} 에서 처리하며 R2 공개 URL/정적 링크는 금지. 2~5권은 미출간 원고이므로 음원 미공개.
- 본문·원고·유료 음성 생성 샘플은 공개 GitHub에 업로드하지 않는다.

## 책별 화자 연출
| 책 | 낭독·대사 지침 |
|---|---|
| 1. 찾아서 | 따뜻하고 담백한 한 명의 내레이터. 독자 질문과 인용은 호흡/말끝의 미세 변화로 구분. 설교조 금지. |
| 2. 다시 살아나다 | 서진우의 방어적 빠른 말끝에서 책임을 인정하는 침묵으로, 윤해인의 조용하지만 흔들림 없는 말투, 기록 담당 김라온의 사실 중심 목소리. 윤해인을 죄책감 회복용 장치로 묘사하지 않음. |
| 3. 함께 살아가다 | 문경의 서두르는 선의, 하림의 자율성을 회복하는 단호함, 미숙의 정확함, 옥자의 생활 감각을 구분. 계층·연령 희화화 금지. |
| 4. 세상으로 흩어지다 | 시온/서리/민하/나경의 관계별 속도 차이, AI 안내 음성은 친절·중립. 지나친 기계 효과 금지. |
| 5. 희년을 열다 | 민석의 실무적 확신, 응식의 경험과 망설임, 주민들의 상이한 경제적 현실. 지역 방언은 억지로 덧붙이지 않음. |

## 고급 음성 검증
1. 원고는 해설/대사/내적독백/인용으로 나누고, 대사 화자 ID를 사람이 검토해 확정. 따옴표만으로 성우를 자동 배정하지 않는다.
2. 캐스팅 ID는 각 권에서 고정, 감정은 과장하지 않고 호흡·미세한 속도·말끝·침묵으로 표현. 화자 간 120~280ms, 장면 간 350~750ms 간격을 시작값으로 개별 검수.
3. 신학 용어·지역명·인명·동음이의어 발음 사전과 청취 QA 체크리스트 생성.
4. 48kHz WAV 마스터(음성엔진 지원 시), 192kbps 이상 MP3 배포본 권장. 클리핑·과도한 압축·지나친 효과음·무단 배경음악 배제.
5. 1권 내레이션, 2권 갈등 대화, 3권 다중 인물, 4권 안내 AI와 사람, 5권 세대 대화에서 각각 2~3분 샘플 검사.
6. 유료 TTS 제공자 비용 및 상업용 사용권 확인 후 **저자 승인** 없이는 유료 생성 요청하지 않는다.
7. 정식 원고 승인·샘플 음질 승인·실제 트랙 전수검사·음원 저장 확인·권한 테스트를 모두 통과하기 전 공개 플래그 설정 금지.

이 문서는 제작 사양이다. 실제 고급 음성 파일의 생성이나 에코디서점 운영 배포를 증명하지 않는다.
