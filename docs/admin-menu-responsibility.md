# EKODI Admin 메뉴 책임 원칙

관리자 페이지는 한 메뉴가 한 가지 운영 질문에 답하도록 구성한다. 다른 메뉴의 상세기능을 편의상 중복 삽입하지 않는다.

| 메뉴 | 주 책임 | 포함하지 않는 내용 |
|---|---|---|
| 통합 운영 | 전체 요약과 진입 지도 | 서비스 상세 설정, 재무 상세 원장 |
| 서비스 · 통계 | 서비스 상태, 운영상태, 서비스별 통계 | 회계, 세금계산서, 고객 회원관리 |
| 재무 · 세금 | 세금계산서, 결제, 회계, 회계구조 | 전체 생태계 Health, Creator AI 요금 |
| 메일 · 라이브 | 메일과 방송 진입/운영 | Social 채널 레지스트리, 클라우드 자료 |
| 클라우드 · 자료 | 공통 자료 저장과 문서 작업 | MarketingAI, 고객사이트, Domains |
| 조직 · 사업 | 법적·사업·사역 조직의 공식 허브 | 결제 상세, 고급관리 중복링크 |
| Clients | 외부 고객 회원·권한·인증 | 서비스 Health, 내부 Admin 계정 |
| Admin | 관리자 계정·권한·Google 인증 | 고객 회원관리 |
| Books | 출판, 유통, 정산, Creator 운영 | 일반 Finance 세금계산서 |
| Creator Billing | Books 안에서 Creator AI 요금·구독 | Toss 일반 결제관제 |
| Community | Community 사역보고와 근거자료 | Social 채널 설정 |
| Social | 기관별 Social 공식채널/노출 정책 | Community 사역보고 |
| MarketingAI | 마케팅 고객, 캠페인, CRM, 채널, 자동화, 승인, 마케팅 과금 | 일반 회계·세금계산서 |
| WORK | 채용공고·지원·사업장·프로필 운영 | Clients 회원 디렉터리 |
| Health | 트래픽·시스템 사용량·운영 건강상태 | Finance 원장 |
| Deployments | 배포와 릴리스 이력 | 시스템 Health 장기지표 |
| Devices | 등록 PC, 진단, 제한된 원격 운영 | 일반 서비스 통계 |
| Domains | 서비스 주소와 라우팅 상태 | Workspace 자료 |

## 구현 계약

1. 정적 섹션은 해당 메뉴 하나의 `data-panel`만 사용한다. `통합 운영`에는 요약 지표만 예외적으로 공유할 수 있다.
2. 동적 기능은 자체 `data-section`과 `data-panel`을 가진다.
3. 기능이 다른 메뉴와 연관되더라도 원본 관리화면은 하나만 둔다. 다른 위치에서는 필요하면 링크나 요약만 제공한다.
4. Finance 내부처럼 한 도메인 안에서도 성격이 다른 작업은 서브탭으로 분리한다.
5. 메뉴 이동으로 기능을 삭제하지 않는다. Creator AI 요금처럼 위치가 잘못된 기능은 적합한 메뉴로 이동한다.
6. 메뉴 무관 콘텐츠가 다시 섞이지 않도록 자동 계약 테스트를 유지한다.
7. Health·통계 같은 외부 조회는 관련 메뉴가 열렸을 때만 요청하여 비용과 트래픽을 줄인다.
