# 목포노회 선교부 2027 운영공간 — 구현 계약

상태: 제안/구현 준비. 공식 목포노회 홈페이지가 아니며 운영 배포 전 검증 필요.

## 라우트
- 공개: /mokpo-presbytery/mission
- 부서 확장: /mokpo-presbytery/departments/:departmentId (추후)
- 기존 EKODI 공통 헤더·푸터, 로그인·역할 권한·감사 로그 재사용. 별도 인증 시스템 금지.

## 2026 가을~2027 가을 임기
- 선교부장: 안좌대리교회 김찬구 목사
- 서기: 에코디교회 정찬균 목사
- 2027년 사업 예산 상한: 3,000,000원 (초안, 의결 전)
- 2026년 가을노회 제135회 선교부 보고서 수입·지출 각각 3,000,000원. 과거 결산과 2027년 계획은 별도 회계연도로 분리.

## 메뉴 및 공개 범위
1. 선교부 소개: 공개, 공식성 고지
2. 사업계획: 공개 요약/비공개 내부 계획
3. 예산·집행: 총괄 공개 여부 승인 후 결정, 증빙은 비공개
4. 회의·일정: 공개 일정/내부 안건·회의록
5. 자료실: 문서별 접근제어
6. 부원 관리: 서기 작성, 부장 검토, 부원 의견, 승인 이력

## 2027 예산안(합계 3,000,000원)
- 정책협의회·세미나 400,000
- 전도목사·전도사역 900,000
- 군선교 500,000
- 농어촌·도서지역 교회 협력 500,000
- 선교부 전체모임 400,000
- 임원회의·운영 200,000
- 예비비 100,000

## 데이터 경계
presbytery_id, department_id, fiscal_year 기반 테넌트/부서 분리. 역할: 공개 방문자, 부원, 서기, 부장, 플랫폼 시스템 관리자. 역할은 서버에서 검증하며 다른 부서 데이터 접근 차단. 집행내역은 승인·증빙·감사 이력 필요. 개인정보 공개 금지.

## 구현·검증 수용 기준
- 기존 사이트 경로와 충돌 없이 실제 경로 200 응답
- PC/모바일 헤더·푸터 일관성, 로그인/로그아웃 확인
- 비로그인 공개 열람, 비인가 쓰기 차단, 부서간 격리
- 예산 합계 3,000,000원 자동 검증, 초과 집행 경고
- 서기 작성 → 부장 검토 → 확정 이력 기록
- 문서 내보내기 및 감사 추적
- CI 통과 → EKODI Orchestrator 보호 병합/스테이징 → 실제 운영 URL 검증. 검증 전 배포 완료 표기 금지.
