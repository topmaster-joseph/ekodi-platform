# EKODI Responsive Web Standard

## 기본 원칙
모든 EKODI 웹페이지는 데스크톱과 모바일에서 같은 콘텐츠 구조를 유지하며, 자연어 문장은 단어 중간에서 임의로 잘리지 않도록 한다.

사용자용 화면은 별도의 USER UI 원칙에 따라 **하나의 중앙축을 공유하는 Centered Canvas**를 기본 레이아웃으로 사용한다. 화면 폭이 달라져도 좌우 여백은 대칭을 유지하고, 모바일에서는 캔버스 폭과 여백만 유연하게 축소한다.

### 타이포그래피
- 한글과 일반 문장: `word-break: keep-all`
- 일반 문장 오버플로 보호: `overflow-wrap: break-word`
- URL, 이메일, 도메인, 인라인 코드: 필요한 경우에만 `overflow-wrap: anywhere`
- 제목: `text-wrap: balance`
- 본문: `text-wrap: pretty`
- 버튼·탭·메뉴·상태라벨도 단어·어절 중간 분리를 금지한다.
- 특정 화면 폭에서만 보기 좋게 만들기 위한 `<br>`·강제 개행은 금지한다. 줄바꿈은 CSS와 실제 문장 구조가 결정해야 한다.
- 화면이 좁아지면 먼저 재배치·줄바꿈·간격 조정을 하고, 읽을 수 있는 글자 크기를 희생하지 않는다.

### 레이아웃
- USER UI의 기본 콘텐츠 캔버스는 최대 `1240px` 안에서 중앙정렬하고, 뷰포트가 좁아지면 좌우 대칭 여백을 남긴 채 축소한다.
- 중앙정렬은 화면 구성의 중앙축을 뜻한다. 긴 본문, 폼 라벨, 표, 목록의 텍스트까지 일괄 중앙정렬하지 않는다.
- full-bleed 배경·지도·영상은 전체 폭을 사용할 수 있지만 실제 읽기·입력·행동 콘텐츠는 다시 중앙 캔버스에 배치한다.
- grid/flex 자식은 `min-width: 0`을 기본으로 하여 좁은 화면에서 컨테이너를 밀어내지 않게 한다.
- 이미지, SVG, 비디오, iframe은 뷰포트를 넘지 않는다.
- 모바일에서 입력 요소와 버튼은 부모 폭을 초과하지 않는다.
- 긴 코드 블록은 문자를 억지로 쪼개지 않고 가로 스크롤을 허용한다.

## 문구 작성·개발 강제 체크
새 UI를 디자인하거나 문구를 작성하거나 CSS/JS를 구현할 때 다음 순서를 필수로 확인한다.

1. 문구 자체가 320px에서도 의미를 잃지 않는지 확인한다. 한 화면에 맞추려고 임의 개행을 삽입하지 않는다.
2. 자연어는 단어·어절 단위로 줄바꿈되고 URL·코드 같은 기술 문자열만 명시적 예외로 처리하는지 확인한다.
3. 고정 폭을 가정하지 않고 Grid/Flex가 자동 재배치되도록 만든다. `min-width: 0`, `minmax()`, `auto-fit/auto-fill`, `clamp()` 등 표준 반응형 수단을 우선한다.
4. 320, 390, 768, 1366, 1440px에서 수평 페이지 오버플로, 텍스트 잘림, 주요 컨트롤 겹침, 의미 손실이 없는지 확인한다.
5. 같은 유형의 수정 요청이 반복되면 개별 페이지를 다시 패치하지 않고 Design Engine·공통 CSS·검증 규칙을 고친다.

이 체크는 리뷰용 권고가 아니라 완료 게이트다. 디자인·문구·개발 중 하나라도 위 계약을 깨면 완료로 처리하지 않는다.

## 적용 정책
`ekodi-platform`의 프로덕션 빌드는 `responsive.css`를 모든 플랫폼 HTML에 자동 삽입한다. 독립 배포 서비스는 같은 표준 파일을 자체 배포물에 포함한다.

USER UI의 중앙 캔버스는 `ekodi-shell-injector.js`와 `shell/user-ui-shell.css`가 public/workspace 사용자 화면에 공통 적용한다. 새 사용자 페이지와 하부서비스는 첫 주 콘텐츠 루트에 `<main>` 또는 `[role="main"]`을 사용하여 이 공통 레이아웃을 자동 상속한다.

새 서비스와 새 페이지는 이 규칙을 기본 계약으로 사용한다. 특정 UI에서 줄바꿈을 금지해야 할 때는 `.ekodi-nowrap`, 긴 식별자나 URL을 강제로 안전하게 감쌀 때는 `.ekodi-break-anywhere`를 사용한다.

## 회귀 방지
반응형 규칙을 제거하거나 `word-break: break-all`을 전역 적용하지 않는다. 모바일·웹 UI 변경 시 320px, 390px, 768px, 1366px, 1440px에서 텍스트 잘림·단어/어절 분리·수평 오버플로·겹침을 함께 확인한다.

USER UI 변경 시 같은 폭들에서 콘텐츠 캔버스의 좌우 여백이 대칭인지, 헤더·본문·푸터의 시각적 중앙축이 일치하는지도 함께 확인한다.
