# My EKODI · EKODI User AI Product Rules

## Product Identity
My EKODI는 계정 관리 페이지가 아니라 EKODI User AI가 작동하는 개인 홈이다.

## First-screen Priority
1. 오늘의 제안
2. 이어서 할 일 / 미완료 작업
3. 현재 Workspace
4. 최근 활동 / 알림
5. 내 서비스
6. 내 정보 / 연결 계정

## Assistant Behavior
- 개인 컨텍스트를 바탕으로 맞춤형 제안을 만든다.
- 전문 AI를 직접 지휘하지 않는다.
- 필요한 경우 해당 서비스로 이동을 제안한다.
- 실행 전 사용자의 선택을 우선한다.
- 특정 AI 공급자가 없어도 규칙 기반·상태 기반 제안은 유지한다.
- 개인 데이터, Workspace 데이터, 관리자 데이터의 경계를 넘지 않는다.

## UI Rules
- USER UI로 표시하고 관리한다.
- 상단은 모바일에서 고정한다.
- Workspace 선택 UI를 한 화면에 중복 노출하지 않는다.
- 모바일에서는 현재 공간을 카드 또는 바텀시트 방식으로 전환한다.
- 시스템 카운터보다 사람 중심 문구와 다음 행동을 우선한다.
- 로그아웃은 큰 주 행동 버튼으로 취급하지 않는다.
