# My EKODI · EKODI User AI Product Rules

## Product Identity
My EKODI는 계정 관리 페이지가 아니라 EKODI User AI가 작동하는 개인 홈이다.

## First-screen Priority
1. 무엇을 원하세요? (행동 입력)
2. 이어서 하기 / 미완료 작업
3. 내 서비스
4. 최근 활동 / 현재 Workspace
5. 내 정보 / 연결 계정

## Assistant Behavior
- 개인 컨텍스트를 바탕으로 맞춤형 제안을 만든다.
- 전문 AI를 직접 지휘하지 않는다.
- 필요한 경우 해당 서비스로 이동을 제안한다.
- 실행 전 사용자의 선택을 우선한다.
- 특정 AI 공급자가 없어도 규칙 기반·상태 기반 제안은 유지한다.
- 개인 데이터, Workspace 데이터, 관리자 데이터의 경계를 넘지 않는다.

## UI Rules
- USER UI로 표시하고 관리한다.
- 상단은 모바일에서 고정한다.
- Workspace 선택 UI를 한 화면에 중복 노출하지 않는다.
- 모바일에서는 현재 공간을 카드 또는 바텀시트 방식으로 전환한다.
- 시스템 카운터보다 사람 중심 문구와 다음 행동을 우선한다.
- 로그아웃은 큰 주 행동 버튼으로 취급하지 않는다.

## 강제 실행 규칙 · Action Hub Contract
- My EKODI의 첫 화면은 기능 카탈로그가 아니라 **개인 실행 허브**로 유지한다.
- 첫 화면 우선순위는 **행동 입력 → 이어서 하기 → 내 서비스 → 최근 활동 → 내 정보** 순서다.
- 큰 설명 카드나 공급자/API 설정을 첫 화면의 주 인터페이스로 올리지 않는다.
- AI 공급자, API Key, 상세 계정 설정은 내 정보의 하위 설정으로 둔다. 기본 화면에는 상태와 진입점만 노출한다.
- 사용자가 승인한 일반 작업은 기존 EKODI Autonomous Operations 규칙에 따라 **현황 파악 → 구현 → 테스트 → 오류 수정 → 재검증 → PR/가드레일 → 스테이징 → 배포 → 실서비스 확인**까지 이어간다.
- 단, 안전·권한·비가역 위험·비용 약정·프로덕션 DNS/토폴로지 변경 등 기존 Human Gate는 우회하지 않는다.
- 서비스 수가 늘어도 첫 화면의 정보 밀도를 늘리지 않고, 실제 연결 서비스와 다음 행동을 우선한다.

## 화면 구성 규칙 · Tab Shell Contract
- My EKODI는 긴 세로 목록을 기본 화면으로 사용하지 않는다.
- 1차 사용자 탐색은 **홈 · 내 서비스 · 내 활동 · 내 정보** 4개 탭으로 고정한다.
- 데스크톱은 상단 탭, 모바일은 하단 고정 탭을 사용하며 같은 정보구조를 공유한다.
- Workspace는 독립 1차 탭으로 늘리지 않고 **현재 공간 선택기**로 제공한다.
- 홈에는 행동 입력과 이어서 하기만 우선 노출하고, 서비스·활동·정보의 상세 내용은 각 탭에서만 연다.
- AI·재무·문서·여정 같은 선택 기능은 필요할 때 직접 진입하는 보조 화면으로 유지한다.

## 단계형 이정표 규칙 · Progressive Wayfinding Contract
- 로그인 후 홈은 **에코디언 안내 → 이정표 선택 → 선택한 내용 1개** 순서로 보여준다.
- 한 화면에서 행동 입력과 이어서 하기를 동시에 펼치지 않는다. 사용자가 이정표를 선택하면 해당 패널만 연다.
- 행동 입력은 **1) 원하는 일 → 2) 현재 맥락 → 3) 실행 확인 → 결과** 단계로 진행하며 한 번에 한 단계만 노출한다.
- 예시 문구를 누르면 바로 실행하지 않고 현재 맥락 단계로 이동한다.
- 내 서비스·내 활동·내 정보는 기존 1차 탭으로 이동해 해당 영역만 표시한다.
- 데스크톱과 모바일은 같은 단계·정보구조를 공유한다. 모바일에서는 이정표를 가로 스크롤형으로 유지한다.
- 에코디언 캐릭터는 장식이 아니라 현재 단계와 다음 행동을 설명하는 안내 역할로 사용한다.

## 2차 이정표 규칙 · Section Wayfinder Contract
- 1차 탭에서 **내 서비스** 또는 **내 정보**에 들어오면 세부 내용을 즉시 펼치지 않고 먼저 이정표 메뉴만 보여준다.
- 내 서비스의 2차 이정표는 **서비스 · 내 공간 · 현황**이고, 하나를 선택하면 해당 패널만 표시한다.
- 내 정보의 2차 이정표는 **기본정보 · 공개·명함 · 나의 에코디언 · 로그인·보안**이고, 하나를 선택하면 해당 패널만 표시한다.
- 세부 화면에는 항상 상위 이정표로 돌아가는 메뉴 버튼을 둔다.
- #workspaces 같은 명시적 딥링크는 해당 세부 패널로 바로 진입할 수 있으나, 상단 1차 탭으로 새로 진입할 때는 이정표 메뉴부터 시작한다.
