# EKODI Money · 국가·공공 환급 통합조회

## 목적
EKODI Money는 여러 기관에 흩어진 환급 가능 항목을 빠짐없이 발견하고, 사용자가 공식기관에서 직접 조회·신청하도록 연결한다.

기본 흐름은 `발견 → 우선순위 → 공식기관 본인인증 → 조회 → 신청 → 지급 확인`이다. EKODI는 환급금이 있다고 추정하거나 금액을 대신 확정하지 않는다.

## V1 조회 범위
- 국세환급금: 국세청
- 지방세 환급: 위택스
- 건강보험 환급금·본인부담상한 관련: 국민건강보험
- 건강(장기요양)·연금 보험료 환급금: 사회보험통합징수포털
- 고용·산재보험 반환금: 근로복지공단 토탈서비스
- 통신 미환급액: 스마트초이스
- 휴면예금·휴면보험금: 서민금융진흥원
- 정부 혜택은 환급금과 구분하여 정부24 혜택알리미로 연결한다.

## 개인정보·권한 경계
EKODI에는 주민등록번호, 계좌번호, 카드번호, 비밀번호, PIN, OTP, 인증코드, 인증서 비밀번호 또는 외부기관 토큰을 입력·보관하지 않는다. 실제 본인인증과 지급계좌 입력, 신청 확정은 해당 공식기관에서만 수행한다.

사용자의 메일·기존 활동에서 확인한 비민감한 기관 이용 흔적은 조회 순서를 정하는 신호로만 사용할 수 있으며, 환급 대상 또는 금액의 증거로 취급하지 않는다.

## API 계약
- `GET /api/refunds/sources`: 공식 조회처와 개인정보 경계를 반환한다.
- `POST /api/refunds/triage`: `tax`, `health`, `pension`, `employment`, `telecom`, `dormant` 같은 비민감 범주 신호만 받아 전수조회 순서를 만든다.
- `POST /api/refunds/handoff`: 선택한 공식기관 URL을 반환한다.
- 금융 실행 및 기관 인증 대행은 지원하지 않는다.
