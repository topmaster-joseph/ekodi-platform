# 에코디 동행 — 서비스별 개인정보·동의 사전 검토문 (초안)

상태: **법률·개인정보 책임자 승인 전. 운영 회원가입/개인정보 수집 활성화 승인 문서 아님**
작성: 2026-10-13 / 변경 관리: EKODI #4617
공개 검토 화면: `https://ekodi.kr/singles/privacy`

## 개통 전 필수 확인

1. 개인정보처리자의 법적 명칭·주소·연락처 및 개인정보보호책임자, 처리 위탁업체와 국외 이전, 보유기간(회원정보/감사/신고 각각), 파기 절차를 실제 운영 계약에 따라 확정한다. 임의의 보유기간이나 연락처를 만들어 표시하지 않는다.
2. 개인정보 수집·이용 필수 동의, 종교·신앙 민감정보 선택 동의, 프로필 공개 선택, 결혼 목적 연결 선택을 각자 분리하고 불필요한 동의를 강요하지 않는다. 철회·탈퇴 동선과 실제 삭제 보존 정책이 일치해야 한다.
3. 승인된 성인확인 기관 결과를 검증해 `adult_verified_at`에 반영하는 *별도 신뢰 경로*를 구현하고, 자기선언이나 Google 인증 이메일을 성인증명으로 오인하지 않는다. 신분증 원문 업로드 금지.
4. 실제 인가된 EKODI Google 로그인 테스트 계정으로 로그인 복귀 → 동의 → 프로필 비공개 저장 → 조회 → 철회·삭제 → 권한 없는 접근 차단을 실증한다. 민감정보·토큰을 로그에 남기지 않는다.
5. 법률 검토 결과에 따라 결혼중개·유료 메시지·행사비·입금 서비스 개통 여부를 별도로 결정한다. 독립된 `SINGLES_*` 게이트를 변경하지 않는다.
6. 확정 문안에 문서 버전과 시행일을 부여하고 UI·API 동의 증빙 버전과 동기화한 뒤 해당 SHA를 검증·승인한다.

## 현행 코드와 다른 보장 사항

현재 `/singles/api/status`의 `onboarding_enabled`, `social_enabled`, `paid_actions_enabled`는 모두 false여야 한다. 동행 공개 소개 및 본 초안 화면은 볼 수 있지만, 실제 회원자료 입력·행사·상대방 연결·입금 등은 사용할 수 있다고 표시하지 않는다. 서비스별 보호 문안이 확정되기 전까지 `/singles/privacy`에는 반드시 **검토 중** 문구를 유지한다.
