# Growth OS 공통 판단 계약 — 목적·증거 준비도 (v1)

**상태:** 비공개 공통 모듈 및 단위 테스트. 실적 평가 API나 자동 조직 의사결정은 아님.

## 목적
에코디 플랫폼은 교회, 선교회, 협동조합, 기관, 매장, 교육·연구 및 사이트의 성장과 지속가능성을 **각각의 목적을 기준으로** 판단한다. 검색 노출·광고·판매는 전문 증거 제공자 중 일부일 뿐이다. Growth OS의 자동 판단은 EKODI Orchestrator의 단일 실행 권한을 대신하지 않는다.

## 코드 계약
- `growth-purpose-evidence-readiness.js`: 순수 함수 `assessGrowthEvidenceReadiness({ workspaceId, profile, purposeConfirmation, observations, asOf, maxAgeDays })`.
- `growth-intelligence-core.js`: 기존 7차원과 목적별 프로필, 읽기 전용 공통 기반.
- `growth-organization-control.js`: *별도 보호 PR #6617 심사 중*. 승인된 최고관리자만 공개·비공개 사이트/워크스페이스 후보 원장을 읽기 전용으로 조회. 해당 원장은 법적 조직 회원명부나 재정 원장이 아니며, 목적 승인이나 증거 접근 권한을 부여하지 않는다.

## 증거 수용
각 평가 차원에 해당하는 서버 측 공식 어댑터에서 승인된 집계값만 받아야 한다. `workspaceId`, 차원별 등록된 `source`, `authorization='authorized_scoped_aggregate'`, 관측 시각, 유한 숫자 값 등을 점검하지만, **이 문자열 필드들은 자체 인증이 아니다.** 인증·워크스페이스 권한·동의·개인정보 접근 범위·해당 공급자의 신뢰는 어댑터가 먼저 검증해야 한다.

- 목적: 해당 워크스페이스 책임 관리자가 확인한 목적·평가 기준으로만 '확인' 처리
- 관측: 숫자 0은 검증된 실제 0으로만 허용
- 미연동, 비공개 처리, 신선도 초과, 출처 불명, 타 워크스페이스 값은 현황/실적으로 추정하지 않음
- 확인된 문제는 공식 증거 참조(`ev:` ID)가 있을 때만 검토 요청
- 종합 서열/성장점수/예상 매출·신뢰점수 자동 산출 없음

## 사용자 경험과 권한
최고관리자 관제 `/admin/ai/growth-os`는 플랫폼 운영 지도이고, 개별 조직 관리자는 자기 사이트에서 본인 권한으로 증거·목적을 확인한다. 공통 엔진은 운영 자금 집행, 대외 게시, 회원 조회나 개인정보 수집을 직접 실행하지 않는다.

4. 교회·선교회·협동조합·매장 각각 서로 다른 목표와 증거의 적정성을 검토
