# EKODI 전문서비스 AI 운영 원칙

상태: 표준
버전: v1
적용 대상: 모든 현재·향후 전문서비스 AI, 외부 연결 전문 AI 모듈, 해당 서비스의 하위 기능

## 1. 핵심 문장

**로그인 전은 초대, 로그인 후는 실행, AI는 사용자의 판단을 빼앗지 않고 다음 행동을 돕는다.**

전문서비스 AI는 기능 목록을 보여주는 포털이 아니라 사용자의 실제 상황·질문·목표에서 시작한다. 내부 시스템 구조를 이해하게 만드는 대신 필요한 다음 행동을 최대 3개까지 먼저 제안한다.

## 2. 사용자 진입 원칙

공개 화면은 단순 회원 차단 화면으로 시작하지 않는다. 로그인 전에도 서비스의 가치, 안전한 기능 미리보기, 짧은 사용 흐름, 무료 시작 경로를 보여준다. 다만 실제 AI 실행, 개인 기록, 기관·공동체 데이터, 저장된 Journey와 작업공간은 인증과 권한 경계 뒤에 둔다.

로그인 후에는 다시 서비스를 설명하는 데 화면을 낭비하지 않는다. 사용자가 하려는 일, 현재 상태, 필요한 다음 행동을 바로 보여준다.

전문서비스마다 색, 타이포그래피, 카드 구조, 정보 밀도와 시각 리듬은 다르게 유지한다. 공통 Shell은 접근성, 반응형 동작, 인증 의미, 개인정보 경계와 EKODI 관계만 공유한다.

## 3. AI 행동 원칙

AI의 기본 역할은 `bounded_professional_delegate`다. 필요한 맥락만 묻고, 결정 가능한 부분은 결정적 규칙을 먼저 사용하며, 모델 호출 없이도 기본 탐색과 이동이 가능해야 한다.

기본 흐름은 다음과 같다.

`이해 → 필요한 만큼만 질문 → 최대 3개 다음 행동 제안 → 위임 범위 안에서 실행 → 검증 → 평이한 결과 보고`

AI는 사실·사용자 입력·추론·초안·기관의 공식 콘텐츠를 구분한다. 불확실성이 중요한 판단에 영향을 주면 숨기지 않는다. 사람이나 하나님의 권위를 사칭하지 않고, 위임받지 않은 권한을 조용히 넓히지 않는다.

## 4. 개인정보와 공유

개인 대화와 기록은 기본적으로 비공개다. 그룹장, 기관 관리자, 목회자, 운영자도 사용자가 명시적으로 공유하지 않은 개인 AI 대화를 기본적으로 볼 수 없다. 공동체·기관 분석은 가능한 한 집계 데이터로 제공한다.

로그인 전 미리보기에는 실제 개인·기관 데이터를 사용하지 않는다. 교차 테넌트 비공개 데이터 접근은 기본 거부이며 별도의 명시적 계약과 권한이 있어야 한다.

## 5. 실행 권한

읽기·관찰은 자동화할 수 있다. 초안·비교·추천은 투명하게 자동 지원할 수 있다. 되돌릴 수 있는 실행은 사전 확인, 권한 범위, 로그, 실행 후 검증을 갖춘 경우에만 제한적으로 자동화한다.

법률·계약·고액 재무·채용/징계·민감한 개인정보 변경·파괴적 데이터 작업·목회적 판단처럼 영향이 큰 결정은 `config/ai-mission-governance.json`의 human gate를 따른다.

## 6. 공급자 독립성

전문서비스는 특정 AI 공급자가 멈춰도 서비스 전체가 멈추지 않아야 한다. 공급자 호출은 EKODI AI Gateway를 통하고, 비밀키는 서버 측에만 둔다. 외부 AI 공급자가 브라우저에서 직접 실행되거나 EKODI DB·Shared Drive에 직접 접근하지 않는다.

외부 전문 AI는 `config/external-ai-module-contract.json`을 통해 연결하며 같은 개인정보·권한·감사·인증 원칙을 상속한다.

## 7. 관리자 운영

전문 AI마다 별도의 관리자 아키텍처를 만들지 않는다. 관리자 페이지의 **AI 서비스 관리**에서 서비스별 활성화, 이용등급, 공급자, 데이터 연결, 프롬프트·전문규칙, 승인정책, 사용량·비용, 로그, 외부 모듈 연결을 공통 방식으로 관리한다.

서비스별 도메인 규칙은 독립적으로 유지하되 공통 권한·보안·비용·감사 계약을 우회하지 않는다.

## 8. 현재 적용 대상

현재 정책은 말씀대화, 오늘의 질문, 마케팅 AI, 에너지 AI, 크리에이터 AI, 지원사업 AI, 배달허브 AI, 경영플랫폼과 AI 기능을 포함하는 출판·교육·머니·보험 서비스에 적용한다.

새로운 전문서비스 AI는 서비스 ID를 등록하고 이 정책 검증을 통과한 뒤 운영에 올린다. 부모 서비스의 하위 기능과 외부 연결 모듈도 같은 정책을 상속한다.

## 9. 완료 기준

전문서비스 AI는 다음 조건을 충족해야 완료로 본다.

- 공개 진입이 사용자의 질문·상황·목표에서 시작한다.
- 로그인 후에는 실제 작업으로 바로 이어진다.
- 개인 데이터는 기본 비공개이며 공유는 명시적이다.
- 고영향 결정은 사람에게 올라간다.
- 공급자 장애 시 핵심 서비스가 완전히 정지하지 않는다.
- 기본 탐색에는 모델 호출이 필수가 아니다.
- 모바일·접근성·오류/빈 상태가 검증된다.
- 하위서비스가 부모 정책을 임의로 우회하지 않는다.
- 운영 변경에는 검증·감사·필요 시 롤백 경로가 있다.

기계 판독 원본은 `config/specialist-ai-service-policy.json`이다.
