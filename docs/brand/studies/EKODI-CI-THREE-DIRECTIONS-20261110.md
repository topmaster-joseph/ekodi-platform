## 공통의 중심 가치
'각자의 자리에서, 함께 가능해지다'는 **카피 후보**다. 에클레시아(자발적 모임), 코이노니아(나눔), 디아스포라(각자의 삶터), 희년(회복)의 설립 정신을 참고하되 특정 도형이 특정 신학적 가치를 소유한다고 주장하지 않는다. 사람·사이트·조직이 독립성을 지키면서 필요한 만큼 연결하는 구조를 표현한다.

- **마스터**: 에코디 / EKODI. 이용자가 읽고 선택할 수 있는 플랫폼의 공통 가치·신뢰 표시.
- **기술 계층**: EKODI Core / EKODI OS. 공개 프랜차이즈 표지가 아니며 제품·고객사이트 CI로 자동 교체하지 않는다.
- **에코디언 / EKODIAN**: 공동체·콘텐츠의 이름 후보; 회원에게 정체성을 강요하지 않는다.
- **각 사이트**: 사이트 소유자의 고유 BI·AI·계약·헤더·푸터·회계·데이터 보존. 외부 가맹점의 상표·색상·본사 가이드는 별도 권리다.

- SVG 3종은 자체 원본 드로잉이며 텍스트·외부 이미지·폰트·제3자 로고를 포함하지 않는다. SVG 자체를 최종 저작권·상표권이라고 간주하지 않는다.
- `64×64` 좌표계, `currentColor` 단색, 브라우저 상속색 사용. 표본색은 깊은 남색 `#182E38`; 이 색을 고객 사이트에 강제하지 않는다.
- 기본 크기 시험: **16 / 24 / 64px**. 장식보다 가독성을 우선한다. 반전색/저시력 대비는 최종 사용자 환경에서 실제 시각 검토가 추가로 필요하다.

## 사용 문안 후보
- 공통 짧은 문장: **각자의 자리에서, 함께 가능해지다.**
- 독립 운영을 명확히 설명하는 문장: **각 서비스는 스스로 운영하고, 필요한 기술과 신뢰만 연결합니다.**
- 영어 참고 문안: **Independent by design. Connected by choice.**
- 이름·문안·시각물은 *최종 승인 이전의 연구안*이다. 타 브랜드의 공식 제휴·인증·소유권을 암시하지 않는다.

## 실제 사이트 적용 시뮬레이션 (배포하지 않음)
1. **EKODI 플랫폼 메인 `/`**: 승인된 시안에 한해서만 마스터 브랜드를 쓸 수 있다. 현재 운영 로고를 자동 대체하지 않는다.
2. **에코디교회 `/ekodichurch` 및 에코디선교회 `/ekodimission`**: 교회/선교회의 고유 머리글·꼬리글·말씀·운영 AI·회계와 종교적 신원은 해당 운영자에게 맡긴다. 마스터 로고 강제 금지.
3. **BBQ 무안청계점 `/bbqcg`**: 가맹점은 기존 본사/점포 BI·계약을 우선한다. EKODI 엠블럼, 색상, 'Powered by', 공동 상표·멤버십을 자동 표시하지 않는다.
4. **청계면상인회 `/cgma`, 지역·시민 고객사이트**: 협회/고객이 가진 고유 브랜드 우선. 플랫폼은 인증·권한·안전 등의 계약된 기능만 제공.

## 디자인·권리 결정의 순서
1. 3개 후보를 흑백·반전·16px 아이콘·명함·웹 헤더에서 확인.
2. 적합한 시안을 사람의 창작적 선택/수정과 함께 확정하며, SVG 원본 SHA·기여·계약·라이선스를 증빙.
3. 원권리자와 마스터 상표 출원인의 실제 법적 이름, `에코디/EKODI` 문자상표와 도형 유사 선행조사, 지정서비스·상품에 대한 공식 KIPRIS 검토.
4. 최종 승인을 받은 뒤에만 **플랫폼 소유 표면 한정** 별도 PR·CI·스테이징·실운영 증거로 교체. 사이트별 고유 BI는 별도 적법한 계약·승인 없이 수정하지 않는다.
5. 실제 법적 출원·납부·서명은 해당 권한을 가진 사람이 별도로 승인한다. 등록 확정 없이 ® 금지.
