# 에코디 사이트별 사명선언 — 직접 운영 서비스 37개 / 1차 홈페이지 20곳

**기준일:** 2026-11-12 · 중앙 오케스트레이터 이슈 #9440

## 원칙
사명선언은 매출을 올리기 위한 문구가 아니라, 각 홈페이지가 사람·지역·이웃·공동체를 위해 존재하는 이유를 한 문장으로 밝히는 **공적 약속**이다.

- **에클레시아**: 서로를 단순 고객·회원이 아닌 존엄한 참여자로 대한다.
- **코이노니아**: 데이터·사역·사업과 관계를 자율적 협력으로 연결한다.
- **디아스포라**: 한 지역·국적·언어·조직의 경계를 넘어 사람의 자리에서 접근한다.
- **희년**: 기회·자원·지식의 불균형을 줄이고 회복과 공정한 순환을 지향한다.
- 종교적 언어를 비종교적 서비스의 사용자에게 강요하지 않으며, 금융·보험·투자 등의 과장된 성과 보장이나 법적 인증을 사칭하지 않는다.
- 실제 이행 여부와 불일치를 사이트 운영자와 사이트 독립 AI가 검토할 수 있도록 사명선언을 별도의 정본으로 유지한다.

## 정본과 게시 범위
- 정본: `config/ekodi-site-missions.json` — 중앙 서비스 등록부의 **37개 에코디 운영 ID·공식명**에 1:1 연결, 서비스별 서로 다른 한국어 사명선언.
- **실제 페이지 소스에 반영**: `/` 모브랜드 소개 및 `/publishing`, `/books`, `/management`, `/edu`, `/insurance`, `/ekodilab`, `/social`, `/community`, `/journal`, `/delivery`, `/business`, `/author`, `/life`, `/work`, `/money`, `/support`, `/energy`, `/ekodicafe`, `/bible` 각 사이트의 소개·첫 화면 맥락.
- 각 사이트 전용 스타일 또는 자체 스타일 블록을 사용한다. `data-ekodi-mission`은 검증 식별자이고, 별도 플랫폼 Shell을 통한 강제 주입은 하지 않는다.
- **독립 소유·배포 사이트**: 교회, 선교회, 지부, 가맹·제휴 매장, 협회, 서남메디 등은 해당 운영자 권한·별도 source/release를 확인하기 전 전역 배포하지 않는다. 특히 독립 계약·가맹점에 에코디 정신을 법적 사명으로 강제하지 않는다.
- `live`가 아닌 사이트는 사명선언 정본에 존재하더라도 실제 공개·검색 색인·서비스 개시를 의미하지 않는다. 기존 PREVIEW/비공개/준비중을 유지한다.

## 이용자 경험
소개를 읽는 바로 다음 맥락에 작은 구획으로 배치:
```text
우리가 존재하는 이유
[이 사이트가 누구를 위해 무엇을 하는지 한 문장]
```
판매 유도 버튼, 시선을 가리는 화면 고정 요소, 서드파티 이미지, 타조직 로고 변경 없음. 글줄과 여백은 PC·모바일 모두 본문 흐름을 따라 적응한다.

## 검증·배포
1. `node --test test/ekodi-site-mission-declarations-20261112.test.mjs test/ekodi-site-missions-native-browser-20261112.test.mjs` 및 full CI, `node scripts/site-chrome.mjs --check`.
2. `node scripts/verify-ekodi-site-missions-native.mjs --plan`은 **계획만** 산출하며 실제 사이트 검증 성공을 뜻하지 않는다.
3. 독립 EKODI Chromium 실행환경에서 `--run`은 공개 `https://ekodi.kr`만 읽고, 본문의 사이트별 고유 사명 문구가 **실제 DOM에 나타나는지** 검증한다. 사이트 5개 이하 × 4화면(컴팩트/모바일/태블릿/데스크톱)으로 분리하고 30 액션 제한 및 외부브라우저 우회를 금지한다.
4. 보호된 EKODI Orchestrator PR/CI, 사명·브랜드 변경 관리자 human gate → 각각의 owner staging/production → 배포 SHA·정본명·공개 DOM·스크린샷·네트워크·콘솔·접근성 확인 후 완료.
5. 실패 시 서드파티나 다른 tenant에 영향을 주지 않는 범위의 PR revert. 본 문서, manifest, 소스 커밋만으로 운영 완료를 주장하지 않는다.

## 지속 개선
각 사이트 독립 AI는 실제 서비스·민원·소통·성과를 바탕으로 사명과 운영이 얼마나 일치하는지 정기적으로 점검할 수 있다. 중앙 오케스트레이터는 집계·보호·일치성 검증만 담당하며 사명 문구를 독단적으로 바꾸거나 승인 없이 이용자의 권리를 제한하지 않는다.
