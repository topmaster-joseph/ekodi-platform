# EKODI 개별 홈페이지 CI 적용 — 1차 소유 사이트 롤아웃
> 2026-11-10 | 이슈 #9234 | 사용자 요청에 따른 **소스 단계의 시각 구현**. 공식 상표 등록·심벌 확정·보호 배포·실운영 검증과는 별개이다.

## 적용 범위 및 세 가지 실제 디자인
- `/`: 기존 EKODI 생태계 글자 및 소개를 유지하고 열린 순환 A를 헤더 앞에 32px 단색 벡터로 표현.
- `/ekodibiz`: 기존 EKODIBIZ 글자·사업 소개·언어별 접근성 제목을 유지하고 나란한 길 B를 전용 홈 헤더에 표현. 브랜드 링크 `ekodibiz.kr` 유지.
- `/ekodimall`: 기존 EKODI MALL과 제휴·구매 고지를 유지하고 정사각 마크의 'E' 대신 마주 열린 문 C를 표시.
- SVG 모두 `aria-hidden`, `focusable=false`이고 소유 사이트명은 일반 텍스트로 남겨 스크린리더·검색 인덱스가 시각 CI에 종속되지 않게 한다. SVG는 외부 이미지·라이선스 폰트·스크립트 없이 사용.
- **동일한 상표권을 주장하지 않음**: 이 세 도형은 연구 시안 #9231/#9233의 홈페이지 활용 테스트이다. 최종 정식 CI 및 사이트별 표장 사용권 결정 전 상표 등록 표기 금지.

## 실행/배포 게이트
1. 해당 소스 주체별 변경만 진행하고, 모두를 공통 Shell로 동일 로고 덮어쓰기 금지.
2. 변경은 `index.html`, `ekodibiz/{index.html,style.css}`, `mall.{html,css}`, 회귀테스트 및 본 문서. DB, auth, payment, 배포·권한 코드 미변경.
3. 정적 검사 → CI 정식 check → EKODI Orchestrator 복구 PR → 스테이징 → **허용된 브랜드 변경 human gate** → 해당 소유자 배포 → 네이티브 PC/모바일 320·390·768·1366 검증.
4. 운영 실증 전 홈페이지 적용 완료를 주장하지 않는다. 중앙 CI 검증 #9228과 고객·가맹 사이트의 정식 상표권 #9198 이슈는 독립 유지.
5. 롤백: 위 소스 파일들의 해당 PR 변경만 revert. 사이트 원장·고객데이터·권한·제3자 브랜드에는 영향 없다.

### 품질 조건
- 공개 헤더에 사이트명·링크·메뉴가 계속 표시.
- 320px 모바일 가로넘침, 초점/탭순서, 배너/공지 가림 여부를 실브라우저로 확인.
- 정식 CI 선정이 달라지면 사이트 소유자 별도 승인을 거친 교체 PR.
