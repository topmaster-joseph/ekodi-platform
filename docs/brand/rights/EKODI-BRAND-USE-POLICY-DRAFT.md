# EKODI 브랜드 사용허락·오남용 방지 초안 (미확정)
> 공식 계약서가 아님. 상표 소유권은 법적 확인 전 미확정.

## 권리 표시
- 브랜드명 EKODI, 에코디는 제안된 마스터 브랜드 정체성이며 **상표 등록/출원 사실을 선언하지 않는다**.
- 승인 전에는 ®, '특허받은 브랜드', '공식 인증' 등의 표현을 금지한다.
- 기호·슬로건은 사용 가능성·디자인 원본 기여·권리 양도/사용약관을 먼저 검증한다.

## 4가지 사용 모델
| 구분 | 사용 원칙 | 배포/표시 |
|---|---|---|
| 플랫폼 고유 | 마스터 권리자·승인된 CI 사용 | ekodi.kr 자체 사명·소개 |
| 독립 EKODI 운영조직 | 허가 조건 아래 고유 BI, 헤더·푸터·회계·독립 AI | 독립 사이트 명칭·표기 |
| EKODI 기술을 사용하는 외부 조직 | 원래 고유 BI 유지, 플랫폼 표지 기본 비노출 | 별도 계약에 따른 선택적 기술 제공 표시 |
| 제3자 프랜차이즈 | 가맹 본사 표장·브랜드 계약이 우선 | 해당 가맹점이 허용받은 범위에서만 사용 |

## 라이선스 계약에 넣을 필드
권리자 법적 명칭, 사용 주체, 표장/매체/지역, 지정상품·서비스, 기간, 품질/브랜드 관리, 승인권·개정 고지, 비용과 재사용 조건, 개인정보/계약 경계, 사용 중지/철회·분쟁 해결, 표장 훼손 방지, 이용자와 고객의 데이터 반출권.

## 운영 AI 및 감사
- 사이트별 독립 AI는 자기 사이트의 소유자 허가를 벗어나 타사 상표·고객 데이터를 취급하지 않는다.
- 중앙 에코디 AI는 **브랜드 사용 상태 요약, 미승인 사용 우려, 만료 알림, 해당 사이트 관리자 '자세히' 링크**만 관리한다.
- 권리침해 의심은 증거 수집, 권리자 검토, 상대 의견 확인 후 수동/법률 승인된 절차를 따른다.
- CI 원본·계약·출원증빙 원문은 해당 법적 주체의 보호된 자료로 유지. 중앙은 무제한 접근할 수 없다.
