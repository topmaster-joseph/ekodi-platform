## 중앙 ekodi.kr의 역할
중앙은 **가치·신뢰·공통 기술·안전·상태보고**를 담당하고, 각 사이트의 사용자 경험·고유 BI·운영·AI·콘텐츠·홍보·회계는 해당 주체가 담당한다. 에클레시아·코이노니아·디아스포라·희년이라는 설립 정신을 부당하게 모든 상업 사이트·프랜차이즈 사용자에게 강제하지 않는다.

### 최상위 홈의 사용자 과업
1. 서비스 찾기: 사역·지역·교육·상거래·금융·지식·AI를 사용 목적에 따라 발견
2. My EKODI: 사용자가 소유하거나 참여하는 사이트로 곧바로 이동, 로그인 후 원래 URL 복귀
3. 신뢰·투명성: 누구의 서비스인가, 무엇이 실제 운영 중인가, 어떤 AI가 무슨 책임을 지는가 명료히 알림
4. 고객 사이트를 중앙 브랜드 UI로 덮지 않는다. 독립 머리글·꼬리글과 BI, 선택적 공통 기술을 제공
5. 중앙 AI는 사이트별 `상태·요약·지표·이상·담당 주체·detailUrl`만 수집; 자세히는 해당 사이트 관리자 화면으로 보안·권한을 다시 검사하여 이동

## site AI 운영 계약의 공통 최소 필드
- `siteId, ownerId, brandId, aiAgentId, delegatedScope, sourcePolicy, permissions, riskGate, summary, detailUrl, lastVerifiedAt, auditReference`
- 사용자 데이터는 사이트에 남고, 중앙은 원문이 아닌 최소 요약. 모든 자동 행위는 변경 가능·감사 가능·철회 가능.
- 공통 AI·인증·결제·홍보·분석 모듈을 선택적으로 재사용. 사이트 전체 자동 통일 작업 금지.

## 단계별 실행
1. 발견: 사이트 권리자, 사업 상태, 브랜딩 자산, 독립 AI, 고객 가치, 권한·동의·도메인 재확인
2. 기획: 고객이 무엇을 하는 곳인지 한 문장과 대표 과업 3개·품질 원칙 작성
3. 설계: 사이트 특성에 맞는 2~3개 BI 시안 및 모바일/PC 경험, 공통 계약
4. 기술: 권한 경계와 사이트 AI의 자율 협력, 중앙 요약 + 개별 관리자 '자세히'
5. 법적 보호: 상표·저작권·특허 후보, 소유권·사용계약·원본증거, 갱신일 관리
6. 검증·출시: 분리 브랜치/PR, 자동 테스트, 스테이징·실운영 검증, 사이트 책임자 승인
7. 최상위 `/ekoditrade` 요청과 매니페스트 `/ekodibiz/trade` 불일치 해결은 별도 라우팅 감사로 진행. 본 기획에서는 기존 주소 임의 변경 금지.
