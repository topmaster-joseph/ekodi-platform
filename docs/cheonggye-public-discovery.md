# 청계잇다 — 공개 지역정보 연결 허브 (v1)

## 목적

청계잇다는 기관·단체·개인의 정보를 중복 생산하거나 소유권을 가져오지 않는다. 청계면을 중심으로 이미 공개된 지역 자원과 기회를 **발견 → 분류 → 연결**하고 원문 출처와 책임 주체를 존중한다.

## 이번 1차 구현 범위

1. 홈 `/cheonggye`에 통합 검색·카테고리·공개 정보 목록을 노출한다.
2. 기존 지역 공개 원장 API `/api/local-operations/cheonggye/modules/{moduleId}` 7종만 읽어 사용자 화면에 연결한다. 기존 작성·수정·승인 및 DB는 변경하지 않는다.
3. URL 또는 제목으로 중복을 줄이고, 검색어·카테고리 필터를 제공한다. 최초 최대 50개 항목을 표시한다. 원문 URL이 있는 항목은 원본으로, 없는 항목은 기존 지역 서비스로 연결한다.
4. 무안군청, 국립목포대학교, 공공데이터포털, 청계면상인회 **공식 원천 페이지로 이동하는 바로가기**를 제공한다. 이 목록은 외부 사이트의 게시물을 자동 수집했다는 뜻이 아니다.
5. 로그인하지 않은 사용자에게는 공개 API 데이터만 제공한다. 상인회 내부 회원·회비·회계·회의 등 비공개 원본은 가져오지 않는다.

## 후속 2차 — 외부 공개 정보 자동 수집 (미구현)

- 정보원별 이용약관·robots.txt·API 라이선스를 점검해 허용된 RSS/API/사이트맵 수집 어댑터를 구성한다.
- 수집 항목: sourceId, originalUrl, title, shortExcerpt, createdAt, verifiedAt, category, locationEvidence, provider, license, reviewState.
- **청계 연관성 검증**: 장소가 청계면인지 확인하고, 인근 지역 정보는 '인근 지역'을 명시한다. 단순 동명 이슈는 제외한다.
- **중복 통합**: canonical URL, 원문 ID, 제목·날짜·장소 유사도. 중복 소스는 모두 출처로 보존한다.
- **관리 및 공개**: 출처가 불명확하거나 개인정보·저작권 문제가 있는 항목은 검수 대기. 승인된 링크 메타데이터만 공개한다.
- **갱신**: 허용된 정보원에 한해 1시간 간격 점검 목표. 갱신 실패와 출처 소실은 명시한다. 캐시·요청 제한·재시도·비상 중단을 둔다.
- **원문 우선**: 전문 무단 복제와 외부 페이지 위장 금지. 링크 오류·정정 요청·삭제 요청 반영.

## 운영 제약

- 공식 EKODI 오케스트레이터의 격리 브랜치 → 테스트 → PR → 필수 CI → Human Gate → 보호 병합 → 스테이징 → 롤백 보호 → 실서비스 검증 순서를 따른다.
- 기존 `/cheonggye` 및 `/cgma`의 콘텐츠 원장과 권한·인증 경계는 변경하지 않는다.
- 동작 확인 전 '외부 자동 수집 완료', '운영 배포 완료'라고 보고하지 않는다.
