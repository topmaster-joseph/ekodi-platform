# EKODI Insurance MVP

`ins.ekodi.kr`을 위한 독립 보험관리 플랫폼의 스테이징 버전입니다.

## 현재 MVP 범위
- AI 보험점검: 상품 추천·적합성 점수 대신 사용자가 입력한 내용에서 확인 우선순위와 근거를 정리합니다.
- My Insurance: 보험사·상품·보험료·점검일을 사용자가 직접 등록합니다.
- Claims Assistant: 상황에 맞는 일반적인 청구 준비자료와 다음 절차를 안내합니다.
- Advisor: 실제 전송 전 단계의 상담 메모를 브라우저에 임시 저장합니다.
- Privacy Center: 저장 중인 로컬 기록 수를 보여주고 전체 삭제 기능을 제공합니다.
- Planner Path: 보험설계사 업무·교육·자격·공식 등록 절차를 확인하기 위한 정보 경로만 제공합니다.

## 개인정보·민감정보 경계
이 스테이징에서는 보험·건강·연락처 입력값을 EKODI 서버로 보내지 않습니다. 브라우저 `localStorage`에만 임시 보관하며 사용자가 Privacy Center에서 한 번에 삭제할 수 있습니다.

현재 입력하지 않도록 안내하는 항목:
- 주민등록번호·여권번호 등 고유식별정보
- 불필요한 상세 병력·검사 원문
- 보험증권 전체 이미지
- 계좌 비밀번호 등 인증정보
- 다른 사람의 건강·보험정보

## 보험업무 경계
현재 제공하지 않습니다.
- 특정 보험사·상품 비교 또는 추천
- 보험 청약·계약 체결 중개
- 보험금 지급 가능성 판단
- 보험사 API를 이용한 자동 청구
- 설계사 모집·위촉 자동 연결

AI 점검은 단순 규칙 기반으로 확인 순서를 제시하며, 사용자는 `AI 점검 기준 보기`에서 사용된 기준을 확인할 수 있습니다. 100점식 건강도/적합성 점수는 사용하지 않습니다.

## 운영 승격 조건
1. 모바일/데스크톱 UX 및 접근성 QA
2. 개인정보·민감정보 별도 동의 문구와 보유기간 정책 확정
3. 통합회원 연결에 대한 공유 Auth 영향검토
4. 보험 데이터 전용 저장소 분리와 최소권한 접근제어
5. 관리자·상담자 역할기반 권한 및 감사로그
6. 상담 전송 API의 최소수집·철회·삭제 흐름
7. 보험 비교·추천 또는 모집 기능을 추가할 경우 별도의 법규·자격·알고리즘 검토
8. 위 조건을 통과한 후에만 `ins.ekodi.kr` 블루-그린 전환

자세한 안전 경계는 `COMPLIANCE_GUARDRAILS.md`, 통합로그인 연결 계획은 `AUTH_INTEGRATION_PLAN.md`를 참조합니다.
