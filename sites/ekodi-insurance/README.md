# EKODI Insurance MVP

`ins.ekodi.kr`을 위한 독립 보험관리 플랫폼의 첫 스테이징 버전입니다.

## MVP 범위
- AI 보험진단: 상품 추천이 아니라 보장 공백·점검 포인트를 정리합니다.
- My Insurance: 보험사·상품·보험료·점검일을 사용자가 직접 등록합니다.
- Claims Assistant: 상황에 맞는 기본 청구서류와 다음 절차를 안내합니다.
- Advisor: 상담 요청을 입력할 수 있습니다.
- Planner Path: 설계사 도전 경로를 보조 메뉴로 제공합니다.

## 중요한 제한
이 브랜치는 UX 검증용입니다. 보험·건강·연락처 입력값은 서버로 보내지 않고 브라우저 `localStorage`에만 보관합니다. 실제 회원 인증, 보험계약 자동수집, 보험금 직접 청구, 상담 전송, 민감정보 저장은 아직 연결하지 않습니다.
