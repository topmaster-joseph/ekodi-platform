# EKODI Office Desktop — pinned upstream and identity preflight

**This is not an installer or a completed editor.** The code verifies upstream source provenance and protects EKODI's future application identity. No executable is packaged, copied, installed or published.

## Upstream baseline (checked 2026-11-21 KST)
- Repository: https://github.com/pblsketch/ieumoffice
- Pinned revision: 904f210367e8d4b1851e81ca1ae342375420a584
- Root and desktop shell specify Apache-2.0. Preserve LICENSE, NOTICE, LICENSE-UNICODE.txt and third-party notices generated by upstream packaging.
- The Electron shell supplies the Windows build command; it also depends on native Rust XLSX and parsing sidecars. This must be tested on an actual Windows environment.
- Upstream installation identifiers, installer name, userData folder, Windows ProgIDs and auto-update feed are the identity of **IeumOffice**, not EKODI. They must be changed before any EKODI-branded package is built.

## Offline preflight
1. Checkout the pinned upstream source SHA into a separate read-only directory.
2. Run: node office-desktop/preflight.mjs /path/to/ieumoffice
3. Run: node --test test/office-desktop-contract.test.mjs
4. Verify third-party, enterprise-only, font and icon licenses and generate SBOM. Never copy original IeumOffice logo/brand art as an EKODI asset.
5. Rebrand every installed-app identity together (app id, product name, packaged name, executable, i18n product constants, Windows file association IDs, userData directory and updater cache/feed). Test side-by-side installation with the original IeumOffice.
6. Build an unsigned and unreleased Windows x64 *test artifact only* under the approved isolated EKODI build, verify actual DOCX/XLSX/PPTX/HWP/HWPX/PDF editing and compatibility. Public binary distribution, signing, automated updates and customer file synchronization are separate governed release decisions.

## Security invariants
- Source is pinned to an exact 40-character SHA; switching to a branch name such as main is not allowed.
- No inherited consumer ChatGPT/Claude login cookies or shared subscriptions; provider credentials remain separate and revocable.
- Cloud sync, external AI export, file associations, updater, user-data migrations and shipping remain OFF in this preflight manifest.
- Personal and tenant document ownership stays governed by the existing EKODI Storage Gateway and server-validated workspace membership.
