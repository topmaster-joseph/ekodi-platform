LOCALREVIEW FIRST
기기 내 미리보기 · 비공개 초안 파일 내용은 서버나 AI 서비스로 전송하거나 자동 게시하지 않습니다. 새로고침하면 미저장 수정이 사라집니다. 공개 전에는 강사·운영자가 자료의 개인정보·저작권·사실관계를 직접 확인하고, 에코디의 승인된 PR·CI·배포 절차를 거쳐야 합니다.
검토 전 초안
01 / SOURCE MATERIALS

강의안·실습자료 가져오기

텍스트, Markdown, CSV, JSON, DOCX, PPTX, HWPX 문서의 텍스트를 기기 안에서 추출합니다. 그림·표 스타일·PPT 애니메이션은 재현하지 않습니다. HWP, PDF, XLSX는 TXT·DOCX·PPTX·CSV로 변환한 후 사용하세요.

첨부한 자료는 자동으로 공개 강의안에 반영되지 않습니다.

02 / INSTRUCTOR REVIEW

회차별 교안 편집

자료를 검토한 뒤 필요한 내용을 직접 수정합니다. 항목별 내용은 줄바꿈으로 구분합니다. 다른 회차로 이동하기 전에 JSON 초안을 내려받으세요.

03 / REVIEW AND HANDOFF

검토·초안 보관

수정한 강의안은 운영환경에 바로 적용하지 않습니다. 구조화된 교안 초안을 내려받아 이후 ChatGPT 대화에 첨부하거나, 에코디 검토 담당자에게 전달할 수 있습니다.

공식 강의자료 출판은 관리자 권한·배포 승인·보호된 CI가 필요합니다. 이 도구에는 공개 게시 버튼이나 서버 저장 API가 없습니다.
