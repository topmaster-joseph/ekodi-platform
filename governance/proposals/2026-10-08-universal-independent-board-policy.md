# EKODI 전체 게시판 공통 강제실행규칙 (제안)

적용 대상: 현재 및 향후 생성되는 모든 EKODI 서비스·독립 사이트의 게시판.

1. **단일 책임**: 게시글·답글·첨부·분류·검색·수정·삭제·감사기록은 독립 게시판 엔진에서 관리한다. EKODI 플랫폼은 인증·권한 전달·사이트 라우팅을 담당한다. 서비스별 추가 업무는 명시적 API 계약으로 연동한다.
2. **단일 저장원**: 같은 게시글을 서비스 내부 저장소와 게시판 저장소에 이중 기록하지 않는다. 구형 계층은 읽기 호환 또는 검증된 마이그레이션 이후 종료하며, 데이터 삭제는 별도 승인과 백업 검증을 요구한다.
3. **분류 계약**: 분류 ID와 표시명은 게시판별 단일 버전 관리 계약으로 정의한다. 작성·목록·검색·필터·관리자 수정·API 검증·DB 제약을 함께 갱신하고 기존 분류값을 호환한다. 서남권 시민의견의 12종은 해당 게시판의 설정이며 전체 게시판에 동일한 12종을 강제하지 않는다.
4. **경로·인증**: /board/x 와 /board/x/ 는 동일한 콘텐츠를 보여야 한다. 직접 접속, 새로고침, 로그인 후 원래 게시물 복귀를 검증한다. 인증용 일회성 값은 주소창·로그에 노출하지 않는다.
5. **사용자·관리자 통합**: 권한이 있는 사용자는 동일 게시판 화면에서 관리 기능을 수행한다. 관리자 전용 시스템·감사 기능은 별도 유지할 수 있다. 서버에서 매 요청 권한을 검증한다.
6. **공개 및 보호**: 공개 게시판의 읽기와 명시적으로 허용된 안전한 익명 의견 등록은 로그인 없이 제공할 수 있다. 파일 업로드·비공개 데이터·관리 작업은 별도 인증과 검증을 적용한다. 남용 방지, 입력 검증, 첨부 검사, 권한 경계를 유지한다.
7. **배포 게이트**: 변경 영향 게시판의 CRUD·답글·첨부·분류·권한·검색·경로·기존 데이터 회귀 테스트를 수행한다. 실패 시 원인 수정 후 재시험하고, 불합격 배포는 완료로 보고하지 않는다. 무관한 경고는 기록하되 과도한 전체 차단을 피한다.
8. **실서비스 실증**: 코드·빌드·라우팅·API·DB·배포 버전과 실제 공개 도메인 동작을 각각 확인한다. 검증되지 않은 단계는 완료로 표시하지 않는다.

이 문서는 정책 초안이다. 전역 강제 적용은 constitution, workspace policy, runtime 및 CI 검증기 반영과 테스트, PR 병합 후 성립한다.
