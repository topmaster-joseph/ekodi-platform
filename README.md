# EKODI Control Center

EKODI의 5개 서비스를 통합 관리하는 관리자·승인 사용자 전용 운영 콘솔입니다.

## 핵심 기능

- 5개 서비스 운영 현황과 핵심 지표 통합 조회
- 가입 요청 승인·거절 및 권한 업무
- 운영 데이터 기반 추천 작업
- 서비스·사용자·작업 통합 검색
- 빠른 작업 명령 팔레트
- 관리자 활동 감사 로그
- Cloudflare Access 연동을 전제로 한 접근 게이트
